    Questions

    Where is my audio processed?

    Your OGG file is sent to a serverless API that calls the Hugging Face Inference API (Whisper large-v3) or AssemblyAI as a fallback. Neither service stores your audio after transcription. No audio is ever retained by this tool.

    Why does it sometimes take 20-30 seconds?

    If the Hugging Face model is cold (no recent use), it needs ~20 seconds to wake up. After that first request, responses are fast. AssemblyAI (the fallback) adds an upload step but is usually quicker for longer files.

    Can I transcribe multiple files?

    Yes. Select or drop multiple OGG files at once (total under 25 MB). They are processed one by one and all transcripts appear in the panel, separated by file name headers.

    How accurate is it?

    Whisper large-v3 achieves under 5% word error rate on clear English speech. You can edit the result directly in the transcript panel before copying or downloading.
